FLOWMD — QUESTION BANK & STUDY SYSTEM (READY TO RUN)
========================================================================

Follow these 2 simple steps to run FlowMD on your laptop:

------------------------------------------------------------------------
STEP 1: OPEN TERMINAL / COMMAND PROMPT IN THIS FOLDER
------------------------------------------------------------------------
• On Windows:
  - Open this folder in File Explorer.
  - Type "cmd" or "powershell" in the address bar at the top and press ENTER.

• On Mac / Linux:
  - Open Terminal and navigate to this folder:
    cd /path/to/FlowMD

------------------------------------------------------------------------
STEP 2: RUN THE LOCAL SERVER
------------------------------------------------------------------------
Choose ANY of the following methods:

METHOD A (Easiest - Python 3):
  python -m http.server 8140

METHOD B (VS Code):
  Open folder in VS Code -> Right click "index.html" -> "Open with Live Server"

METHOD C (Node.js):
  npx serve -l 8140 .

------------------------------------------------------------------------
STEP 3: OPEN IN BROWSER
------------------------------------------------------------------------
Open Google Chrome / Edge / Brave and go to:
👉 http://localhost:8140/#/curriculum

------------------------------------------------------------------------
HOW TO USE THE QUESTION BANK:
------------------------------------------------------------------------
1. Click the "MCQ's / Q-Bank." toggle at the top of the Curriculum page.
2. Select any MBBS subject (e.g. Anatomy, Surgery, Pathology, etc.).
3. Expand any chapter accordion.
4. Click the cyan "MCQ" button next to any topic to start practicing questions!
5. Tick checkboxes to mark topics complete, or use "MARK DONE" for entire chapters.
6. All progress is saved automatically offline on your laptop.
